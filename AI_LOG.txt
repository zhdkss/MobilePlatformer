AI USAGE LOG — GEM RUNNER
Author: Abris Dias
Tool: Claude (Anthropic), chat + computer control of the Unity editor

1. CODE
- The AI explained how each mechanic works (Rigidbody2D movement, ground check,
  triggers, coroutines, Instantiate, SceneManager, Input System actions) and gave
  example code for each script.
- I typed every script myself in Assets/Scripts, studied it line by line and can
  explain it: SceneLoader, PlayerController, PlayerHealth, PlayerShooter,
  CoinCounter, Pickup, Hazard, LevelExit, Enemy, Bullet, Boss.
- Later I added extensions the same way (explanation + example, typed by me): stomping enemies
  (Enemy.cs), bullets killing enemies (Bullet.cs), boss movement (Boss.cs),
  sound calls (AudioSource.PlayClipAtPoint) in the player, boss and pickup scripts.

2. EDITOR / SCENES
- With my permission, the AI controlled the Unity editor on my computer to speed
  up setup: creating scenes and objects, tile layout of the levels, Inspector
  wiring, HUD and Canvas settings, colors and fonts, extra enemies and gems.
- I tested every level, reported problems and decided what to change
  (harder Level 2, enemy stomp, boss movement, more enemies, shooting in all levels).
- I wired parts of the UI myself (Win screen menu button).

3. ASSETS MADE WITH AI
- Sound effects (jump, pickup, hurt, shoot, boss hit, win) and the background
  music loop were generated by the AI with code.
- Joystick and JUMP / FIRE button images were drawn by the AI as pixel art.

4. PROBLEMS AND HOW THEY WERE SOLVED
- On-screen stick error "Cannot find control <Gamepad>/leftStick" -> re-selected
  Left Stick [Gamepad] as the control path.
- Gem counter not visible -> Canvas Scaler reference resolution was portrait
  (1080x1920); changed to 1920x1080 and anchored the counter to the top-right.
- NullReferenceException in PlayerHealth / CoinCounter -> Hearts array and Label
  were not assigned in the Inspector.
- Boss took no damage -> its collider was not a trigger (Is Trigger off).
- Enemy did no damage -> no trigger collider / no damage script on it.
- No sound + NullReferenceException on jump -> AudioClip fields were empty;
  sounds were played at the gem position far from the camera, so
  PlayClipAtPoint now uses the camera position.
- Hero stuck on walls after a short jump -> wall friction; added a Physics
  Material 2D with friction 0 as the default 2D material.
- Joystick/buttons hard to hit on the phone -> made them bigger and opaque,
  added labels JUMP / FIRE.
- Unity Remote "Not Connected" -> found in Editor.log that Unity sees the iPhone
  but the connection is refused by the Remote app; used "Any iOS Device".
